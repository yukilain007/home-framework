# Continuity contract examples

These fictional YAML files demonstrate the optional `continuity/` protocol. They contain no
personal data and do not change the default HOME workflow. Copy them only into a workspace you
control, review them, and replace the fictional content before use.

`memory-candidate.yaml` and `recall-decision.yaml` are intentionally excluded from compiled
handoffs. A candidate is a proposal, not an approved fact; a recall decision is an inspection
record, not a permission grant.
